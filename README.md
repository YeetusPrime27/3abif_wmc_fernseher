## How to style with CSS


| Element               | Gestaltung                                |
|-----------------------|-------------------------------------------|
| Hintergrund 	        | Helle, zum Thema passende Farbe           |
| Hauptüberschrift      |  	Dunkle Akzentfarbe, zentriert           |
| Zwischenüberschriften | Akzentfarbe und unterer Rahmen            |
| Schrift               | Arial, gut lesbare Textgröße              |
| Bild                  | 300 px breit, abgerundete Ecken           |
| Links                 |	Akzentfarbe; bei hover unterstrichen    |
| Abstände              |	Sinnvolle margin- und padding-Werte     |
